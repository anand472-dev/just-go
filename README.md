# just-go

`just-go` is a Go port of [`just`](https://github.com/casey/just), the command runner, ported from `casey/just` v1.59.0. It aims to read the same justfiles and behave the same way, and it is checked against the upstream binary with a conformance corpus.

Credit: `just` is created by Casey Rodarmor and its contributors. This project is a reimplementation and is not affiliated with upstream.

Module path: `gitea.com/wimwian/just-go`

Status: the project is in its foundations milestone. The repository layout, the impure-boundary package (`internal/sys`), and the tooling are in place; the language implementation follows.
