# Cases the pinned oracle (oracle/bin/just) fails under the conformance
# harness, with the reason. TestConformance skips them.
#
# Format: one entry per line, "<case id> <category>: <reason>". Blank lines
# and lines starting with "#" are comments. The category must be one of
# exceptionCategories in runner_test.go; parsing rejects any other.
#
# Two tests keep this list honest: TestOracleExceptionsNameCorpusCases
# (every id is a corpus case) and TestOracleExceptionsStillFail (with
# JUST_GO_BIN=oracle/bin/just, every listed case still fails; one that
# passes is stale and must be removed).
#
# The categories are closed (ledger ruling R9):
#   path-hash    a .justcache file named after the recorder's temporary path,
#                which differs on every machine and run
#   machine-env  a variable inherited from the recording machine, such as USER,
#                or a fact about that machine, such as its architecture
#   fifo         a named pipe fed by a thread in the upstream test, which the
#                corpus cannot record
#   strict-path  a path upstream allows and just-go's strict path rule refuses
#   unsupported-shell  a completion script for a shell the spec does not target
#                (elvish, nushell); just-go refuses to generate it
#                (the documented divergence; the oracle passes these cases)
# Empty directories, symbolic links, and file modes are recorded (R8) and the
# harness materializes them, so they are never a reason here.
